# Macland – Tilkynningar (app)

WordPress-viðbót fyrir Macland iPhone-appið: push-tilkynningar (APNs), Live Activity fyrir pöntunarstöðu og gögn fyrir appið sem eru lesin af macland.is.

Uppfærslur: vefurinn sækir nýjasta *release* héðan sjálfkrafa (stillingar → GitHub-geymsla og lykill).
Ný útgáfa = hækka `Version:` og `VERSION` í `macland-push.php`, tag með sama númeri, release.
